Configure NoHorny from the server console with Mindustry's `config` command.

```bash
config nohorny-auto-mod-policy DELETE_NSFW
```

| Key                             | Default                            | What it does                                                                           |
| ------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------- |
| `nohorny-auto-mod-policy`       | `BAN_NSFW`                         | What to do when a group is classified.                                                 |
| `nohorny-api-endpoint`          | `https://nohorny.xpdustry.com/api` | Classification server. Set to `null` to stop classifying.                              |
| `nohorny-api-auth-type`         | `DISABLED`                         | `DISABLED`, `BASIC`, or `BEARER`.                                                      |
| `nohorny-api-auth-value`        | empty                              | `username:password` for BASIC, the raw token for BEARER.                               |
| `nohorny-discord-webhook`       | empty                              | Discord webhook for alerts. Setting it sends a test message.                           |
| `nohorny-discord-webhook-name`  | empty                              | Username on those messages. Leave empty to keep the webhook's own name.                |
| `nohorny-discord-webhook-proxy` | `false`                            | Proxy Discord requests through [ProxyScrape](https://proxyscrape.com/free-proxy-list). |
| `nohorny-debug-tap`             | `false`                            | Admin double-tap debugging.                                                            |

## Policies

| Policy        | What it does                                                |
| ------------- | ----------------------------------------------------------- |
| `DISABLED`    | Nothing. Classification still runs.                         |
| `DELETE_NSFW` | Deletes groups rated NSFW.                                  |
| `DELETE_WARN` | Deletes groups rated WARN or NSFW.                          |
| `BAN_NSFW`    | Deletes groups rated NSFW and bans the author. The default. |

If the plugin cannot identify an author, `BAN_NSFW` still deletes the group and skips the ban.

## Debug tap

```bash
config nohorny-debug-tap true
```

An admin can double-tap a tracked display or canvas. NoHorny labels the group in-game and writes a
PNG under `config/mods/nohorny/debug/`.

## Plugin API

```gradle
repositories {
    maven { url = uri("https://maven.xpdustry.com/releases") }
}

dependencies {
    compileOnly("com.xpdustry:nohorny-common:VERSION")
    compileOnly("com.xpdustry:nohorny-client:VERSION")
}
```

Subscribe to `ClassificationEvent`. The author may be missing.

```java
import arc.Events;
import com.xpdustry.nohorny.client.ClassificationEvent;
import mindustry.mod.Plugin;

public final class MyPlugin extends Plugin {
    @Override
    public void init() {
        Events.on(ClassificationEvent.class, event ->
                System.out.println("Rating: " + event.response().rating()));
    }
}
```

Or set the same options the console uses:

```java
import com.xpdustry.nohorny.client.AutoModeratorPolicy;
import com.xpdustry.nohorny.client.NoHornyClientAuthType;
import com.xpdustry.nohorny.client.NoHornySetting;
import java.net.URI;

NoHornySetting.API_ENDPOINT.set(URI.create("http://localhost:8080"));
NoHornySetting.API_AUTH_TYPE.set(NoHornyClientAuthType.BEARER);
NoHornySetting.API_AUTH_VALUE.set("my-token");
NoHornySetting.AUTO_MOD_POLICY.set(AutoModeratorPolicy.DELETE_WARN);
```
